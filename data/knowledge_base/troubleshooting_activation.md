# License Activation Troubleshooting

## Error 0x80070005 (Access is denied)
This error means the activation tool lacks permission to write the license file. Ask the customer to close the application, re-open it with administrator rights (Run as administrator), and retry activation. If it still fails, check that security software is not blocking the license folder.

## Activation limit reached
Each license activates on up to 3 devices. Deactivate an old device from the license portal, or escalate to support if the device is no longer accessible.

## Wi-Fi and router connectivity
For intermittent Wi-Fi drops, ask the customer to restart the router, check the status LEDs, and move to the 5 GHz band. Persistent drops after a firmware update should be escalated.
